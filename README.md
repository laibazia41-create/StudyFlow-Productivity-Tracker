# StudyFlow ⏱️📈

StudyFlow is a modern, mobile-first productivity application designed for students to track focus sessions, manage tasks with contextual color tags, and monitor weekly progress analytics.

## 🚀 Key Features
- **Isolated User Workspaces:** Data structures automatically sync and isolate safely based on the logged-in email.
- **Smart Task Management:** Tasks feature visual hierarchy via custom color-coded category badges.
- **Interactive Focus Timer:** A custom circular Pomodoro tracker engineered with live pause/resume runtime logic.
- **Account Recovery Pipeline:** A secure, token-simulating system enabling professional password modification workflows.
- **Responsive Layout:** Tailored with a mobile-first user experience using clean modern glassmorphism UI variables.

## 🛠️ Tech Stack
- Frontend markup structured using semantic HTML5 layout engines.
- Styling engineered via modern component-driven CSS variables and animations.
- Dynamic behaviors, form engines, canvas drawing rendering, and state workflows built on native JavaScript.
- Client-side persistence maintained using asynchronous browser `localStorage` matrices.
